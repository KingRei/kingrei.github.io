Python 100days - Day 18 - Tarjan - one DFS with timestamps, three structures / Tarjan：一個 DFS 時間戳，三種結構

指著一張網路拓撲圖問三個問題。哪一條線路斷掉會讓網路裂成兩半？哪一台機器掛掉會帶走半個網路？ 哪幾個服務彼此都到得了，所以改動其中一個，影響會繞一圈回到自己身上？

聽起來是三個問題，其實是同一次 DFS，只是每個節點多記了兩個整數。

Day 17 講的是「假設的代價」——Dijkstra 用「沒有負權」換速度，前提一破，它會安靜地給你錯的答案。 今天剛好相反：一個我們早就會的走訪，身上一直帶著我們沒去撿的資訊。
